FUNKLAGE – THW-inspiriertes Funk-Escape-Spiel
============================================

Vier vollständig spielbare Szenarien:
- Operation Regenkamm: Hochwasser
- Operation Lichtpunkt: Stromausfall
- Operation Sturmspur: Sturmschäden
- Operation Brückenschlag: Behelfsbrücke

SO STARTET IHR
1. ZIP-Datei vollständig entpacken; alle Dateien in einem Ordner lassen.
2. Spiel_starten.html mit einem modernen Webbrowser öffnen.
3. Szenario auf der Startseite wählen.
4. Das zum Szenario passende Fuehrungsstelle_*.pdf ausdrucken
   oder der zweiten Gruppe auf einem separaten Gerät geben.
5. Team A (Trupp) nutzt die Spielkonsole.
   Team B (Führungsstelle) nutzt ausschließlich das Handbuch.
6. Beide Teams tauschen Aufgabeninformationen nur mündlich aus.

Für Ausbildende:
- Spielanleitung_Ausbildung.pdf
- Fuehrungsstelle_Alle_Szenarien.pdf (alle 4 Regelhefte zusammen)

Spielregeln: sechs Abschnitte je Szenario, maximal drei Fehlversuche,
Zeitlimit 15/25/35 Minuten oder unbegrenzt. Neue Zufallsdaten pro Start.
Nach Abschluss kann eine lokale TXT-Auswertung gespeichert werden.

Voraussetzungen: Browser mit aktiviertem JavaScript; keine Anmeldung,
kein Internet und keine Installation erforderlich. Funkgeräte selbst
sind nicht Teil des Spiels.

HINWEIS: Unabhängige, nicht offizielle THW-inspirierte Übung.
Keine Freigabe oder Anleitung für reale Einsatzmaßnahmen.
Keine echten Einsatzrufgruppen verwenden.
